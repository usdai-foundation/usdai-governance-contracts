## Usage

### Clone

```shell
$ git clone --recursive https://github.com/metastreet-labs/usdai-governance-cotracts.git
```

### Build

```shell
$ forge build
```

### Test

```shell
$ forge test
```

### Submodules

### Update

```shell
$ git submodule deinit --force .
$ git submodule update --init --recursive
```
