## Usage

### Clone

```shell
$ git clone --recursive https://github.com/usdai-foundation/usdai-governance-contracts.git
```

### Build

```shell
$ forge build
```

### Test

```shell
$ forge test
```

### Submodules

### Update

```shell
$ git submodule deinit --force .
$ git submodule update --init --recursive
```
